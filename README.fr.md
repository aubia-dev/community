## Le cockpit Aubia

Aubia est un cockpit desktop au-dessus de Claude Code, Codex CLI et Mistral. Un agent implémente et un modèle d'une autre famille relit : les deux s'échangent le diff jusqu'à convergence, et un désaccord persistant vous revient. Le [profil de l'organisation](https://github.com/aubia-dev) présente aussi le Mode Opinions vers Plan exécutable, BYOK et la feuille de route.
